PriceLog Ver.0.8

買い物中の価格比較に特化したPWA試作版です。

主な機能
- 商品一覧をコンパクト表示
- 商品名 / 内容量 / 最安店舗 / 最安単価を一覧表示
- 商品をタップしたときだけ店舗入力欄を展開
- 店舗ごとに1行入力
- 入力中にリアルタイムで税込単価を計算
- %OFF / 円引きクーポン対応
- 税込 / 税抜入力対応
- 標準税率 / 軽減税率を設定画面から変更
- localStorage保存
- JSONバックアップ / 復元
- PWA / GitHub Pages対応
